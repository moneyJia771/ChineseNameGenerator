# 中文取名神器

一个简单易用的中文取名H5网站，帮助父母为宝宝取一个寓意美好的中文名字。

## 功能特点

- 支持姓氏和性别选择
- 提供单字名和双字名选择
- 多种名字风格：传统经典、现代时尚、文艺诗意和独特少见
- 每个名字都附带详细的含义解释和出处
- 支持名字收藏和分享功能
- 移动端友好的响应式设计

## 使用方法

1. 输入宝宝的姓氏
2. 选择宝宝的性别（男孩/女孩）
3. 选择名字长度（单字/双字）
4. 选择名字风格
5. 点击"生成名字"按钮
6. 从生成的名字中选择喜欢的，点击心形图标收藏
7. 点击"分享结果"按钮，将收藏的名字分享给亲友

## 技术栈

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## 本地运行

```bash
# 克隆仓库
git clone https://github.com/moneyJia771/ChineseNameGenerator.git

# 进入项目目录
cd ChineseNameGenerator

# 使用任意HTTP服务器运行，例如
python -m http.server 8000
```

然后在浏览器中访问 `http://localhost:8000`
